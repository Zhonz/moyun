## 功能测试用例

### P0 - 核心功能

- [ ] **页面加载**: 页面在 3 秒内完成首次渲染
- [ ] **模板选择**: 点击模板卡片能正确选中并高亮
- [ ] **收藏功能**: 点击星标能正确切换收藏状态
- [ ] **AI 生成**: 能成功调用 API 并显示生成结果
- [ ] **历史记录**: 能正确保存和加载历史记录
- [ ] **设置面板**: API Key 保存和模型选择正常
- [ ] **主题切换**: 深色/浅色主题能正确切换

### P1 - 重要功能

- [ ] **搜索功能**: 模板和历史搜索能正确过滤结果
- [ ] **复制功能**: 复制按钮能正确复制内容到剪贴板
- [ ] **分享功能**: 分享功能在支持的浏览器正常工作
- [ ] **流式输出**: AI 生成使用流式输出实时显示
- [ ] **续写功能**: 能正确延续之前的内容
- [ ] **导出功能**: 历史记录能正确导出为 Markdown

### P2 - 辅助功能

- [ ] **打字效果**: 光标闪烁动画正常
- [ ] **Toast 提示**: 操作反馈提示正常显示
- [ ] **加载指示器**: 生成过程中加载指示器正常
- [ ] **错误处理**: API 错误能正确显示错误信息

## 已知兼容性问题

| 问题 | 浏览器 | 解决方案 |
|------|--------|----------|
| 某些 CSS 动画在低版本 Safari 不支持 | Safari < 14 | 使用 `prefers-reduced-motion` |
| `navigator.share` 在 iOS Safari 有限制 | iOS Safari | 降级到剪贴板复制 |
| IndexedDB 在某些隐私模式不可用 | 隐私模式 | 降级到 localStorage |
| WebSocket 在某些网络环境被阻止 | 企业网络 | 使用 HTTP 轮询降级 |
